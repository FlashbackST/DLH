✅ The 3 sharing rules

  1. Share with named people, never “anyone with the link”.
  2. Give only what they need – “can view” if they don't need to edit.
  3. Remove access when the work is done or someone leaves.

No donor or beneficiary data in WhatsApp groups or private email addresses.

Back up: the 3-2-1 rule

3📄📄📄copies of your data
2💻 🖴different kinds of storage
1🔌🚫copy offline – unplugged

Does your NGO do this?

🔐 Why one copy must be offline

Ransomware locks every file it can reach – the computer, shared drives, plugged-in USB drives and synced cloud folders. Cloud syncing is not a backup: it syncs the locked files too. Only the copy that was unplugged stays clean.
